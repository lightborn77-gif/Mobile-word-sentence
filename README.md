# word&sentence

폰과 PC 브라우저에서 쓰는 단어·문장 학습 앱입니다. 설치 없이 이 페이지를 열면 됩니다.

**실행:** https://lightborn77-gif.github.io/Mobile-word-sentence/

폰에서는 위 주소를 연 뒤 브라우저 메뉴의 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있습니다.

## 하는 일
- 단어·문장 리스트를 불러와 음성(TTS)으로 읽어 주고, 퀴즈와 반복 학습으로 외웁니다.
- 영어, 중국어, 일본어를 지원합니다.
- 선택 기능(플러그인): 영어 발음기호, 중국어 병음, 한자 정보, 영상 스크립트(유튜브 주소로 재생하며 문장 쉐도잉).

## 알아 둘 것
- 하나의 파일(`index.html`)로 동작합니다. 학습 리스트와 기록은 사용하는 기기의 브라우저 저장소에만 저장되고 서버로 보내지 않습니다.
- 앱에는 학습 리스트가 들어 있지 않습니다. 본인의 리스트를 불러와서 쓰세요.
- 영상 스크립트의 재생은 유튜브 재생기를 쓰므로 인터넷이 필요하고, 이 페이지처럼 `https://` 주소로 열어야 합니다.
- 발음·병음·한자·예문 기능은 CMUdict, CC-CEDICT, KANJIDIC, Tatoeba 등 공개 자료를 바탕으로 합니다.
